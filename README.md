# ZenFS bundles

[![Built with Ona](https://ona.com/build-with-ona.svg)](https://app.ona.com/#https://github.com/OpenOS-Project-OSP/zenfs-bundle) [![KDE Eco](https://img.shields.io/badge/KDE%20Eco-certified-brightgreen?logo=kde&logoColor=white&style=flat-square)](https://eco.kde.org/) [![Blue Angel](https://img.shields.io/badge/Blue%20Angel-DE--UZ%20215-0055a4?style=flat-square)](https://www.blauer-engel.de/en/certification/criteria)

`@zenfs/bundle` provides a collection of bundles for ZenFS packages.

> [!CAUTION]  
> **You should not use these bundles in production.**
>
> You will miss security updates for dependencies, tree shaking, and the ability to customize your own build process
